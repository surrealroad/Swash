Export and print documents. File › Export as PDF… and Export as HTML… save the document as it looks in the Preview, with math, Mermaid diagrams, alerts, footnotes and images included. HTML exports are a single self-contained file. File › Print… (⌘P) prints it, and Edit › Copy as Rich Text and Copy as HTML put the whole document on the clipboard for Mail, Pages or Google Docs. On iPhone and iPad the same commands are in the Export menu.
