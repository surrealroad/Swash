Outline and statistics: a heading outline sidebar (View ▸ Show Outline, ⌃⌘S) follows the caret and jumps to a heading when you click it. The status bar now counts only the text readers see. Click the count to switch between words, characters, characters without spaces, paragraphs and reading time; with text selected it shows "selected of total". Format ▸ Insert Table of Contents adds a linked list of headings. The Edit menu gains Copy Heading Link (⌃⌘C), Copy as Markdown Link and Copy File Path.
