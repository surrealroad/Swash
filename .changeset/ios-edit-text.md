Formatted mode on iPhone and iPad is now the full Edit Text editor, as on the Mac. You edit the text in place with its Markdown syntax hidden: headings, emphasis, links, quote and alert boxes, lists with bullets and tap-to-toggle checkboxes, code blocks with language badges, rules, images, editable tables and rendered math and Mermaid diagrams. Return, Backspace and Tab work on lists, the formatting bar and edit menu apply formatting in place, and edits restyle only the blocks they change. Slack mrkdwn documents still show the read-only preview in Formatted mode.
