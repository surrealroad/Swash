On the Mac, File › Open Folder… (⇧⌘O) opens a folder of Markdown files in one window. The first file opens straight away, and a sidebar lists the others so you can switch between them. Edits are saved automatically. Files that are added, renamed, deleted or changed in other apps show up right away, and the New File button adds a Markdown file to the folder.
