Syntax highlighting for many more code languages. A new built-in tokenizer colours JavaScript, TypeScript, Python, Swift, Go, Rust, Ruby, Java, Kotlin, C, C++, C#, Objective-C, PHP, Scala, Dart, SQL, Bash/shell, HTML, XML, CSS/SCSS, JSON, YAML, TOML/INI, Markdown and diff (with common aliases such as `js`, `ts`, `py`, `sh`, `zsh`, `yml`, `c++` and `cs`), including block comments, multi-line, template and triple-quoted strings, numbers, keywords, types and built-ins. The same colours, adapted for Light and Dark Mode, are used in Edit Text, the Preview and Quick Look, and exported HTML and PDF colour code too. The code-language menus list the new languages.
