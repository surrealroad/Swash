Add images by dragging them onto a document or pasting them, including screenshots. Swash copies the image into an `assets` folder beside the document and inserts a relative `![](assets/…)` link; images already in the document's folder are linked where they are. The folder can be changed (or left empty to use the document's own folder) in Settings › General › Images. If Swash doesn't have permission to write to the folder, it asks for access first. An untitled document has to be saved before a screenshot can be pasted into it.
